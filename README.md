# SeamanOG - Dənizçi İmtahan Platforması

⚓ Dövlət Dəniz və Liman Agentliyinin (DDLA) imtahan sualları əsasında hazırlıq platforması.

## Xüsusiyyətlər

- **4600+ sual** 74 PDF fayldan çıxarılıb
- **3 kateqoriya**: Sıravi Heyət, Xüsusi Hazırlıq, Sertifikat/Diplom
- **74 mövzu** üzrə imtahan
- **Random sual seçimi** - hər imtahanda fərqli 20 sual
- **Real vaxt nəticə** - imtahan sonunda ətraflı nəticə
- **PDF materiallar** - bütün PDF-lərə baxış və yükləmə
- **Axtarış sistemi** - sual və mövzu üzrə axtarış
- **Admin panel** - statistika və idarəetmə
- **Tam responsive** - mobil, planşet, desktop

## İstifadə

Saytı açın və ya GitHub Pages-də yerləşdirin.

## Məlumat Mənbəyi

Bütün suallar [DDLA.gov.az](https://ddla.gov.az/exams) saytından götürülüb.
